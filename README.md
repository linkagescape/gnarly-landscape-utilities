Gnarly Landscape Utilities
==========================

Tools for resistance and habitat raster ("core area") creation and processing.

Developed by Brad McRae, Andrew Shirk, and Jim Platt

Housed by The Nature Conservancy from inception until November 2026, when it was moved to the Linkage Mapper Project.
